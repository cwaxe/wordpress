# WX Schwerpunkt

Rechner für Masse und Schwerpunkt (Weight & Balance) direkt auf der Website. Flugzeuge, Hebelarme, Grenzen und Zuladungsposten werden im Backend gepflegt.

- Beliebig viele Flugzeuge mit Leermasse, Hebelarmen, Schwerpunktgrenzen (mm und %MAC), MTOM und Kraftstoffdaten
- Zuladungsposten frei festlegbar, mit Min./Max. und Pflichtfeld
- Zeigt die maximal zulässige Kraftstoffmenge für die eingetragene Beladung (MTOM, Schwerpunktgrenzen, Tankinhalt)
- Prüft Startmasse, Schwerpunkt beim Start und bei leerem Tank sowie die Grenzen jedes Postens
- Eingabefelder sind bei jedem Aufruf leer
- Übernimmt die Farben des Themes

Einstellungen: *Einstellungen → Schwerpunkt*.

```
[schwerpunkt]                     erstes Flugzeug
[schwerpunkt flugzeug="d-mdmp"]   bestimmtes Flugzeug
```
