Schlanke Pop-ups für Ankündigungen, z. B. das Flugplatzfest. Ohne Cookies, ohne Tracking.

== Beschreibung ==

* Inhalt im Block-Editor (Bild, Text, Buttons …), Menüpunkt „Pop-ups“
* Pro Pop-up: an/aus, Zeitraum von/bis, nur Startseite / alle Seiten / ausgewählte Seiten
* Öffnen nach einstellbarer Verzögerung
* Wiederholung: bei jedem Aufruf, einmal pro Besuch oder erst wieder nach X Tagen
  (gespeichert im Browser per localStorage/sessionStorage, keine Cookies – kein Eintrag im Cookie-Banner nötig)
* Nach einer Änderung am Pop-up sehen es alle Besucher noch einmal
* Breite klein / mittel / groß / automatisch, Schließen per ×, Esc oder Klick daneben
* Links auf #popup-123 öffnen ein Pop-up von Hand
* Vorschau-Link in der Liste, Status-Spalte (aus / geplant / wird angezeigt / abgelaufen)
* Übernimmt vorhandene Pop-ups aus Popup Maker beim Aktivieren
* Übernimmt die Farben des Themes (CSS-Variablen --karte, --text)

== Umstieg von Popup Maker ==

1. WX Popup installieren und aktivieren. Beim nächsten Aufruf im Backend werden alle Pop-ups
   mit Inhalt, Seiten, Verzögerung, Wiederholung und Aktiv-Status übernommen.
2. Unter „Pop-ups“ prüfen, dann Popup Maker deaktivieren und löschen.
