# WX Popup

Schlanke Pop-ups für Ankündigungen, z. B. das Flugplatzfest. Ohne Cookies, ohne Tracking.

- Inhalt im Block-Editor, Menüpunkt *Pop-ups*
- Pro Pop-up: an/aus, Zeitraum von/bis, nur Startseite / alle Seiten / ausgewählte Seiten, Verzögerung
- Wiederholung: bei jedem Aufruf, einmal pro Besuch oder erst wieder nach X Tagen (im Browser gespeichert, keine Cookies)
- Breite klein / mittel / groß / automatisch, Schließen per ×, Esc oder Klick daneben
- Links auf `#popup-123` öffnen ein Pop-up von Hand
- Vorschau und Status in der Liste
- Übernimmt vorhandene Pop-ups aus Popup Maker beim Aktivieren
